Machine Learning Introduction (ML)
    Empowers machines to learn from data
    Improve performance without explicit programming
    
ML can be defined as a set techniques that enable computers to learn 
from past experiences or data unlike tradition programming where you need 
explicit instructions to dictate the program's behavior.

ML algorithms identify patterns in data, which they use to make predictions or
decisions without human intervention. 

Machine Learning Overview
    Machine Learning encompasses a variety of techniques and algorithms that can
    solve complex problems across different domains.

    Understanding the fundamentals is crucial for successfully applying 
    Machine Learning to real-world challenges and innovations.
